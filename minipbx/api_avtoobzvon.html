API автообзвона MiniPBX

Базовый URL: http://xxx.xxx.xxx.xxx:9000

 

Важно: Все запросы к API должны использовать заголовок Content-Type: text/plain, даже если тело запроса выглядит как JSON.

1. Запуск задания автообзвона

Запускает задание автообзвона по имени, которое уже создано и настроено на АТС.

Тип запроса: POST
Endpoint: /auto_call/start
Заголовок: Content-Type: text/plain

Вариант 1: Запуск готового задания (со своим списком номеров на АТС)

Тело запроса:

json

{"name":"тест"}

Пример cURL:

bash
curl -X POST 'http://xxx.xxx.xxx.xxx:9000/auto_call/start' \
-H 'Content-Type: text/plain' \
-d '{"name":"тест"}'

Вариант 2: Запуск задания с указанием списка номеров

Тело запроса:

json

{"name":"тест","list":["1002","1003","1004","1005"]}

Пример cURL:

bash
curl -X POST 'http://192.168.88.121:9000/auto_call/start' \
-H 'Content-Type: text/plain' \
-d '{"name":"тест","list":["1002","1003","1004","1005"]}'

Ответы:

Успешный запуск:

json

{

"result": "ok",

"result_txt": "Задание тест запущено",

"id": 506

}

Задание уже выполняется:

json

{

"result": "warning",

"result_txt": "Задание тест уже выполняется",

"result_code": "already_running"

}

Задание не найдено:

json

{

"result": "error",

"result_txt": "задание тест не найдено",

"result_code": "not_found"

}

 

2. Проверка статуса выполнения

Получает информацию о ходе выполнения запущенного задания.

Тип запроса: GET
Endpoint: /auto_call/status
Параметр: id — идентификатор задания (из ответа на запуск)

Пример запроса:

text

GET http://192.168.88.121:9000/auto_call/status?id=506

Пример cURL:

bash
curl 'http://192.168.88.121:9000/auto_call/status?id=506'

 

Ответ:

Успешный ответ:

json

{

"result": "ok",

"state": "run",

"total": 10,

"done": 5,

"success": 0,

"tried": 5,

"attempts": 5,

"comment": "state - состояние (none - не выполнялось, run - выполняется, finish - выполнено, pause - приостановлено, stop - прервано); total - общее количество номеров; tried - количество номеров, до которых были попытки дозвониться; success - количество успешных попыток; attempts - общее число попыток дозвона; done - количество номеров до которых дозвон закончен"

}

Задание не найдено:

json

{

"result": "error",

"result_txt": "задание 506 не найдено",

"result_code": "not_found"

}

3. Получение результатов обзвона

Возвращает детальную информацию по каждому номеру в задании.

Тип запроса: GET
Endpoint: /auto_call/result
Параметр: id — идентификатор задания

Пример запроса:

text

GET http://192.168.88.121:9000/auto_call/result?id=506

Пример cURL:

bash
curl 'http://192.168.88.121:9000/auto_call/result?id=506'

 

Ответы:

Успешные звонки:

json

{

"result": "ok",

"data": [

{ "number": "1002", "result": "ok", "result_code": "talk" },

{ "number": "1003", "result": "ok", "result_code": "talk_ok" }

]

}

Неудачные звонки:

json

{

"result": "ok",

"data": [

{ "number": "1002", "result": "fail", "result_code": "busy" },

{ "number": "1003", "result": "fail", "result_code": "timeout" }

]

}

Пояснение полей data:

Примечание: В сценариях могут использоваться дополнительные коды result#1, result#2, result#3 — они устанавливаются в настройках сценария на АТС.

4. Управление заданием

Позволяет ставить на паузу, возобновлять или останавливать выполнение задания.

Тип запроса: GET
Endpoint: /auto_call/start
Параметры:

id — идентификатор задания

cmd — команда:

task_pause — поставить на паузу

task_resume — продолжить после паузы

task_stop — полностью остановить

Пример запроса (пауза):

text

GET http://192.168.88.121:9000/auto_call/start?id=506&cmd=task_pause

Пример cURL:

bash
curl 'http://192.168.88.121:9000/auto_call/start?id=506&cmd=task_pause'

Ответы:

Команда выполнена:

json

{

"result": "ok",

"result_txt": "Выполнение задания приостановлено"

}

Предупреждения:

 

Ошибка:

json

{

"result": "error",

"result_txt": "задание 506 не найдено",

"result_code": "not_found"

}
