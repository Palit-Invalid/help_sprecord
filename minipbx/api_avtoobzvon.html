Автообзвон: Руководство пользователя по API

Система автообзвона позволяет автоматически обзванивать сотрудников или клиентов по заданному списку номеров. Управление происходит через запросы, которые можно отправлять через браузер, специальные программы или встраивать в интерфейсы.


 

1. Запуск задания (POST-запрос)

Чтобы робот начал обзванивать, нужно отправить системе название сценария и список номеров.

Как это работает

Вы отправляете POST-запрос с JSON-данными, в которых указываете:

name — название сценария (задания), заранее созданного в АТС.

list (необязательно) — список внутренних номеров для обзвона. Если список не указан, используется тот, что привязан к сценарию.

Формат запроса

POST https://api.youraccount.ats.com/auto_call/start Content-Type: application/json

Пример 1. Запуск со стандартным списком (из сценария)

json

{  "name": "напоминание" }

Пример 2. Запуск со своим списком номеров

json

{  "name": "напоминание",  "list": ["1002", "1003", "1004", "1005"] }

Что вы получите в ответ

Успешный запуск

json

{  "result": "ok",  "result_txt": "Задание напоминание запущено",  "id": 506 }

Важно: сохраните ID задачи (506) — он понадобится для всех следующих шагов: проверки статуса, получения результатов и управления.

Задание уже выполняется

json

{  "result": "warning",  "result_txt": "Задание напоминание уже выполняется",  "result_code": "already_running" }

Значит, это задание уже запущено. Дождитесь его завершения или остановите текущее.

Задание не найдено

json

{  "result": "error",  "result_txt": "задание напоминание не найдено",  "result_code": "not_found" }

Проверьте название сценария — возможно, опечатка или его еще не создали в АТС.


 

2. Проверка статуса задания (GET-запрос)

В любой момент можно посмотреть, как идет обзвон: сколько номеров обработано, сколько успешно, есть ли пауза.

Формат запроса

GET https://api.youraccount.ats.com/auto_call/status?id=506

(где 506 — ID вашей задачи)

Что вы получите в ответ

Успешный ответ

json

{  "result": "ok",  "state": "run",  "total": 10,  "done": 5,  "success": 3,  "tried": 7,  "attempts": 7 }

Расшифровка:

state— состояние: run (выполняется), pause (на паузе), finish (завершено), stop (остановлено), none (не запускалось)

total— всего номеров в задании

done— сколько номеров уже обработано полностью

success— сколько успешных разговоров

tried— сколько номеров пробовали обзвонить (с учетом повторов)

attempts— общее количество попыток дозвона

Задание не найдено

json

{  "result": "error",  "result_txt": "задание 506 не найдено",  "result_code": "not_found" }


 

3. Получение детальных результатов (GET-запрос)

После обзвона (или даже во время него) можно посмотреть подробный отчет по каждому номеру.

Формат запроса

GET https://api.youraccount.ats.com/auto_call/result?id=506

Что вы получите в ответ

Успешный ответ

json

{  "result": "ok",  "data": [    {      "number": "1002",      "result": "ok",      "result_code": "talk"    },    {      "number": "1003",      "result": "fail",      "result_code": "busy"    },    {      "number": "1004",      "result": "dialing",      "result_code": ""    }  ] }

Расшифровка:

number— внутренний номер абонента

result— итог: ok (успешно), fail (неуспешно), dialing (в процессе). Если поля нет — звонок еще не совершался

result_code— детальный код результата

4. Управление заданием (GET-запросы)

Если нужно вмешаться в процесс, используйте команды управления.

Поставить на паузу

text

GET https://api.youraccount.ats.com/auto_call/start?id=506&cmd=task_pause

Ответ: Выполнение задания приостановлено

Продолжить после паузы

text

GET https://api.youraccount.ats.com/auto_call/start?id=506&cmd=task_resume

Ответ: Выполнение задания возобновлено

Полностью остановить

text

GET https://api.youraccount.ats.com/auto_call/start?id=506&cmd=task_stop

Ответ: Задание остановлено

Шпаргалка: что и когда использовать

Важно запомнить

Базовый адрес (https://api.youraccount.ats.com) — уточните у администратора вашей АТС.

ID задачи — сохраняйте его сразу после запуска, без него вы не сможете проверить статус или результаты.

POST-запрос используется только для запуска. Все остальные действия — это GET-запросы.

Если вы запускаете задание с тем же именем, пока предыдущее еще работает — получите предупреждение.
